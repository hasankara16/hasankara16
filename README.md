# Merhaba, ben Hasan! 👋🏻

**SAP Lojistik (MM, SD, PP)** alanında, özellikle **Malzeme Yönetimi (MM)** üzerine uzmanlaşmayı hedefleyen bir SAP fonksiyonel danışman ve uzman kullanıcı adayıyım.

Satın almadan stok yönetimine, fatura kontrolünden raporlamaya kadar uçtan uca MM süreçlerini; "hangi ekranda ne yapılır"dan öte, **arkasındaki iş mantığıyla** öğrenmeye odaklanıyorum. SAP S/4HANA eğitim ortamında gerçek senaryolar (P2P, fason üretimi, stok hareketleri) uygulayarak teoriyi pratikle pekiştiriyorum.

Bunun yanı sıra **iş analizi** alanıyla da ilgileniyorum; süreçleri anlama, veriyle çalışma ve raporlama tarafında kendimi geliştiriyorum.
